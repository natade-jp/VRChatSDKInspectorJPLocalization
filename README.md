# VRChatSDK-Inspector翻訳機

Unityを日本語表示にしても英語のまま残る、VRChat SDK Inspectorの項目を日本語で補完するWindows向けツールです。

**VRC Phys Bone、VRC Phys Bone Collider、VRC Contact Sender、VRC Contact Receiver、VRC Avatar Descriptorの各項目の翻訳を収録しています。** 収録件数はアプリ画面で確認できます。未収録の項目やUnityの翻訳機能を利用しない表示もあるため、すべての英語表示が日本語になるわけではありません。

## 対応環境

- Windows 10 / 11（64bit）
- **動作確認済み：Unity 2022.3.22f1**
- 別バージョンもインストール先の手動指定で使用可能（動作未検証）
- 対象Unityの日本語Language Packがインストールされ、Unityの表示言語が日本語であること

配布版には必要な実行環境と翻訳データが含まれます。.NETやCSVファイルを別途インストール・配置する必要はありません。

画面の「収録翻訳：N件」は、その配布版に含まれる翻訳の件数です。コメントや同じ英語の重複を除いて数えます。Unity標準の翻訳と重なる項目も含むため、実際に追加される件数とは異なる場合があります。

## 起動方法

1. 配布されたZIPファイルを任意のフォルダーへ展開します。
2. 展開したフォルダーの`VRChatSDKInspectorJPLocalization.exe`をダブルクリックします。

フォルダー内の`README.md`がこの説明書です。テキストエディターでも読むことができます。

## 翻訳のインストール

1. **Unity Editorをすべて終了**します。
2. 本ツールを起動し、Unityのインストール先と「日本語Language Pack」の状態を確認します。
3. 「管理者権限で再起動」を押し、Windowsの確認画面で許可します。
4. 「インストール」を押して、表示された対象フォルダーを確認します。
5. 完了後、Unity Editorを起動して表示を確認します。

通常の起動時には管理者権限を要求しません。Unityの共有ファイルを変更する操作に管理者権限が必要です。再起動の確認をキャンセルした場合は、通常権限のまま状態確認を続けられます。

### Unityのインストール先

初回は次の標準的なインストール先を自動で確認します。

```text
C:\Program Files\Unity\Hub\Editor\2022.3.22f1
```

見つからない場合や別の場所を使用する場合は、「インストール先を変更…」から選択してください。`Editor`フォルダーが入っている`2022.3.22f1`相当のフォルダーを選びます。`Unity.exe`や`ja.po`そのものを選ぶ必要はありません。

指定したフォルダーは保存され、次回起動時に再利用されます。バージョンは実行ファイルからではなく、選択したフォルダー名（例：`2022.3.22f1`、`6000.0.1f1`）から取得します。別バージョンも`Editor\Unity.exe`と`Editor\Data\Localization\ja.po`がある構造なら選択できます。フォルダー名からバージョンを取得できない場合や必要な構造がない場合は操作できません。

2022.3.22f1以外は画面に「動作未検証」と表示します。別バージョンでの日本語化は保証していませんが、同じファイル構造と読み込み可能な翻訳形式であればインストールを試せます。

### 日本語Language Packが見つからない場合

Unity Hubで対象Editorの日本語Language Packを追加してください。案内ダイアログの「日本語化の方法を開く」から[Unity Editorを日本語化する手順](https://blog.natade.net/2026/10/03/unity-editor-japanese/)を開けます。追加後、本ツールの「状態を再確認」を押してください。

## 翻訳を更新するには

新しい配布版を展開し、Unity Editorを終了してから、新しいEXEを起動してください。「管理者権限で再起動」の後に「再インストール」を押すと、その配布版に収録された翻訳へ置き換わります。

ファイルを展開しただけでは、Unityに適用済みの翻訳は更新されません。

## 翻訳を削除するには

Unity Editorを終了し、本ツールを管理者権限で再起動して「アンインストール」を押してください。本ツールが追加した翻訳部分だけを削除します。

配布フォルダーやEXEを削除しただけでは、Unityに追加した翻訳は削除されません。必要に応じてアンインストールを先に実行してください。

## 知っておいていただきたいこと

- このツールはUnityの`Editor\Data\Localization\ja.po`へ翻訳を追加します。**同じUnity Editorを使用するすべてのプロジェクトに影響します。**
- Unity標準の翻訳がすでに存在する項目は、標準の翻訳を優先します。
- 操作前に`ja.po`と同じフォルダーへ`ja.po.vrcjp-日時-識別子.bak`というバックアップを作成します。バックアップは自動削除しません。
- ファイルの状態に異常がある場合は、自動修復せず操作を中止します。ほかの翻訳編集ツールも終了してから使用してください。
- Unityの更新・再インストール・Language Packの再導入によって翻訳が消えることがあります。その場合は状態を再確認してください。別バージョンのUnityへ古い`ja.po`やバックアップをコピーしないでください。

## 困ったときは

| 状況 | 確認すること |
| --- | --- |
| インストールボタンを押せない | 管理者権限、対応Unity、日本語Language Packの状態を確認してください。インストール済みの場合は「再インストール」を使用します。 |
| Unityが実行中と表示される | すべてのUnity Editorを終了してから操作してください。 |
| インストール状態異常・読み込み失敗が表示される | 表示された理由と詳細ログを確認してください。バックアップを戻す場合は対象と日時を確認し、その後の他の変更も戻ることに注意してください。通常の削除には「アンインストール」を使用します。 |
| インストール後も英語のまま | Unityを日本語表示にして起動し直してください。未収録の項目や、Unityの翻訳機能を利用しない表示には適用できません。 |

エラー詳細は次のファイルへ保存されます。問い合わせの際は、エラー画面の内容とあわせて確認してください。

```text
%LOCALAPPDATA%\VRChatSDKInspectorJPLocalization\errors.log
```

Unityのパス設定は同じフォルダーの`settings.json`へ保存されます。
